## Specificity verdict
Partly product-grounded (hashes, diff counts, View on GitHub, Obsidian callouts, mono + serif pairing) but the composition is generic admin kit. Git disappears for readers: no commit, author or path on a page. Detector: 0 static findings (TSX is regex-only); runtime overlay found mostly Mermaid false positives, one confirmed truncation without a tooltip.

## Priority issues
- P1 Wide Mermaid flowcharts shrink to ~7px labels (3px on phones). Keep natural width with sideways scroll, cap shrink, add tap to expand. globals.css .mermaid-diagram svg.
- P1 Mobile pages drawer is not a real modal: no Escape, focus stays on body, page behind stays reachable. Use a native dialog like the search palette. mobile-nav.tsx.
- P1 Most pages have no <title> (/, /login, /admin/*, /account/password). WCAG 2.4.2. Title template in app/layout.tsx.
- P1 Markdown pipeline (parse5, micromark, Shiki, KaTeX) ships to the browser because search-palette.tsx imports pageHref from lib/render/markdown.ts. Move pageHref to its own module; mark markdown.ts server-only.
- P1 Archive from Projects lands on a form preselected to the first project. Deep link with the project and open its confirm.
- P2 Focus is faint (1px at 50%); primary buttons 2.2:1 light; no skip link.
- P2 Search snippets show raw table pipes and Mermaid source, strip underscores; weak match marking; combobox ARIA incomplete.
- P2 Contrast misses: code labels 4.49:1, tip/danger callout titles 4.40/4.24:1, diff-removed keyword 3.93:1.
- P2 Touch: logo link 18px, View on GitHub 16px tall, primary buttons stay 36px on touch.
- P2 Account hand-off: no generate or copy for temp passwords, no sign-in block after create.
- P2 Admin tables are divs; "+11 ~0 -15" reads as symbols.
- P2 Link nested inside <summary> in the sidebar.
- P2 404 copy should say "or you don't have access".
